Troubleshooting & Support Case Studies

1. Windows Print Spooler & Service Recovery

OS & Network Printing

Issue: Department-wide network printing stalls caused by corrupted spooler jobs crashing the Windows Print Spooler service across shared workstations.

Resolution: Isolated the stalled print queue, stopped the spooler service via command line, cleared corrupted .SPL and .SHD files from the system spool directory, updated print drivers, and restored normal office printing workflows.

2. Hardware Diagnostics & Thermal Optimization

Hardware Maintenance

Issue: User workstations experiencing severe CPU thermal throttling, unexpected shutdowns, and storage bottlenecks during daily workloads.

Resolution: Conducted component-level hardware diagnostics, verified NVMe and SATA SSD interface compatibility and drive health, cleaned dust buildup from heatsinks, applied fresh thermal compound, and verified stable operating temperatures under load.

3. Identity & Access Management / Onboarding Support

IAM & Remote Access

Issue: Remote new hires unable to access internal file shares, corporate email, and VPN tunnels on day one due to incomplete group policies and MFA sync delays.

Resolution: Provisioned Active Directory accounts with role-based security groups, assigned Microsoft 365 licenses, guided users through MFA enrollment and VPN client configuration, and documented a standardized onboarding checklist.
